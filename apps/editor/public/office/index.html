Analog Canvas for PowerPoint

Draw analog circuit schematics on your slides and edit them again later. The picture on the slide is a crisp vector drawing; the circuit itself travels inside the presentation, so whoever opens it with the add-in can keep editing. The add-in runs the current Analog Canvas editor every time: there is nothing to update.

Works in PowerPoint for Windows, Mac and the web.

Install

Download the add-in file

PowerPoint on the web

  1. Open a presentation, then Home → Add-ins → More Add-ins.
  2. Choose My Add-ins → Upload My Add-in and pick the downloaded file.

PowerPoint for Mac

  1. Quit PowerPoint.
  2. In Finder, choose Go → Go to Folder… and open ~/Library/Containers/com.microsoft.Powerpoint/Data/Documents/wef (create the wef folder if it is missing).
  3. Copy the downloaded file into it and start PowerPoint.
  4. Home → Add-ins: Analog Canvas is under Developer Add-ins.

PowerPoint for Windows

  1. Put the downloaded file in a shared folder, for example \\your-computer\addins.
  2. File → Options → Trust Center → Trust Center Settings → Trusted Add-in Catalogs: add the folder's address, tick Show in Menu and restart PowerPoint.
  3. Home → Add-ins → My Add-ins → Shared Folder: choose Analog Canvas.

Use

  1. Home → Analog Canvas opens the pane. Choose New circuit, or start from an example.
  2. Draw in the editor window, then click PowerPoint in its header: the drawing lands on the slide. The dot turns green once the slide shows what you drew.
  3. To edit, click the circuit on the slide once and choose Edit in the pane. (Double-click opens PowerPoint's own picture tools.)
  4. A presentation with a circuit opens the pane by itself the next time, on any computer that has the add-in.

Privacy

Your circuits are stored in your presentation. The editor runs in the add-in's window and does not upload a drawing unless you choose to, for example by publishing it to the Gallery. See the privacy notice.
