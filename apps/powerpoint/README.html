Circuit Canvas for PowerPoint

An optional local integration for Windows x64 desktop PowerPoint. The slide displays a transparent SVG; the complete editable Project, displayed Cell and three previous saved snapshots travel with the picture.

Install

Save and close PowerPoint and any circuit editor windows. Extract the entire ZIP to a permanent folder, then double-click install.cmd in Windows File Explorer. This registers the add-in for your Windows user without administrator privileges. Restart PowerPoint and open the Circuit Canvas tab. Keep the extracted folder in place.

Draw and edit

  1. Select the destination slide and choose New circuit.
  2. Draw in the local editor. Press I to insert a component, R to rotate, W to wire and Esc to end an operation. Text fields retain normal typing.
  3. Choose Save to PowerPoint and wait for the acknowledgement. The drawing returns to the slide where you opened the editor, even if you switched slides.
  4. Save the presentation in PowerPoint with Ctrl+S. The editor's Ctrl+S saves its local Project; it does not save the presentation.

To continue later, select the circuit picture and choose Edit circuit. Position, size, rotation and stacking order are preserved on update. Keep one editor window open at a time. Select Open history version to choose an earlier save, or Export selected circuit for a portable .icproj.json copy of the selected circuit's editable data.

Close and recovery

Save to PowerPoint and close waits for PowerPoint to accept the snapshot. A failure or edits made during saving keep the editor open. Other Project tabs save locally. Closing without updating leaves the slide's previous drawing intact. If PowerPoint is busy with a dialog, dismiss it; the pending update is received automatically. Save the presentation afterwards.

Explicit saves also keep local recovery copies in %LOCALAPPDATA%\CircuitCanvas\Sessions. Shared library components live in %LOCALAPPDATA%\CircuitCanvas\components.json; placed components travel in the Project, but unused library components require copying that file to another computer.

Update and uninstall

Save and close both applications before installing from a new permanent folder. Run uninstall.cmd to remove this add-in's registration. Presentations and recovery files remain. Use Export selected circuit before converting pictures to shapes or removing document metadata.

Compatibility

Tested with Microsoft 365 PowerPoint on Windows x64. macOS, web PowerPoint, Windows ARM and 32-bit Office are not supported by this package. The offline editor provides drawing and export; hosted accounts, Gallery publishing and cloud simulation are not supplied. Other computers can display the SVG without the add-in; editing requires installing it. Replacing the SVG does not preserve picture-specific animations, cropping, hyperlinks or effects.
