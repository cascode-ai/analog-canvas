# Diagnostic decisions

Use current-revision diagnostics and read `category`, `confidence` and
`gateEligible` beside severity: structural findings can block under the quality
policy; observations with `gateEligible:false` never block.

| Finding                               | Inspect or repair                                                                                                                                                                                                                                                                                                                                                                               |
| ------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Unresolved symbol / unplaced instance | Resolve mapping or placement before routing it; never guess pins                                                                                                                                                                                                                                                                                                                                |
| Ambiguous Junction                    | Compare exact Nets and geometry; remove misleading branch placement without changing intended connectivity                                                                                                                                                                                                                                                                                      |
| Constraint violation                  | Keep locks; adjust the responsible unlocked area                                                                                                                                                                                                                                                                                                                                                |
| Symbol/label overlap                  | Compare strokes and text in the render. Parts meeting pin to pin (a supply T, a coil on a source) are not overlap. Free text over a label or struck by a wire is reported (`VISUAL_LABEL_CLEARANCE`, text first): move the text. Text over an outline is not reported. Text is measured in the served Metropolis face (its ICM Greek for Greek, DejaVu for math), as the editor and PNG draw it |
| `VISUAL_LABEL_CROWDED`                | A part's name or value is under 2 units (`parameters.clearance`) from the stroke edge of a wire, rail, junction dot or part drawing without touching it; text drawn over one is `VISUAL_LABEL_CLEARANCE`. Warning, never gating. Run `arrange-labels` (`includeManual:true` for hand-moved labels) or move the label                                                                            |
| `VISUAL_LABEL_RUN_ON`                 | Two parts' labels on one row less than a figure apart read as one string; move one. Information only; one part's own labels are exempt                                                                                                                                                                                                                                                          |
| `VISUAL_PORT_ON_JUNCTION`             | A formal `port` or `port-filled` lands directly on a dotted wire junction, abutting the junction dot against the port circle. Move the Port off the trunk and connect it with a short orthogonal stub                                                                                                                                                                                           |
| Wire through symbol                   | Check strokes and endpoints; box overlap is not proof. A wire running back across its own part is information: route it out of the pin first                                                                                                                                                                                                                                                    |
| Route overlap                         | Same-Net collinear spans may be a shared trunk; remove only redundant geometry                                                                                                                                                                                                                                                                                                                  |
| `ERC_OVERLAPPING_NETS`                | Two Nets along one line read as shorted; reroute one off the span, never add a Junction or merge Nets                                                                                                                                                                                                                                                                                           |
| `ERC_UNDRIVEN_GATE_NET`               | Every pin only senses voltage (gates, bulks, block inputs). Wire it to the bias, source or Cell Pin meant to drive it; a label is not a driver; never add a part just to silence it                                                                                                                                                                                                             |
| `ERC_UNCONNECTED_CELL_PIN`            | A Port its Cell does not connect: a wire ending on its artwork without joining its pin, or one never wired. Connect the wire to the Port's pin; never delete the Pin a parent wires                                                                                                                                                                                                             |
| `ERC_LOOKALIKE_NET_NAMES`             | Two Net names differ only by `0`/`O` or `1`/`l`/`I`. If they are one node, rename one to the other; otherwise rename one so they no longer look alike                                                                                                                                                                                                                                           |
| `ERC_CONFLICTING_VOLTAGE_OUTPUTS`     | Ideal sources or behavioural outputs (op-amp, logic, comparator) forcing one Net. Check the source figure for a wire drawn to the wrong Net; never add a resistor just to silence it                                                                                                                                                                                                            |
| `ERC_OPAMP_POSITIVE_FEEDBACK`         | A behavioural fully differential op-amp connects `OUT+` to `IN+` or `OUT-` to `IN-` with no negative feedback, closing a latching positive loop. Rewire feedback to the opposite-sign input (`OUT+` to `IN-`, `OUT-` to `IN+`); swapping the symbol alone keeps existing Net attachments                                                                                                        |
| `ERC_SWITCH_CLOCK_DC`                 | A switch clock is set only by a DC source, so its switches never toggle. Give the clock source a PULSE waveform (with the complementary phase its own), or drive the clock from the testbench; never delete the source                                                                                                                                                                          |
| `ERC_SWITCH_CLOCKED_BY_OWN_NAME`      | A switch still shows its own name beside phased switches, so it gets a clock pin of its own. Write its phase on its label (set-switch-control), the complement where the figure shows one                                                                                                                                                                                                       |
| `ERC_PARALLEL_SWITCHES`               | Switches across the same two Nets: on one clock, a duplicate; on two clocks, usually one wired to the wrong Net. Check the figure and rewire or delete the extra                                                                                                                                                                                                                                |
| `ERC_NO_DC_PATH`                      | Nets held only by capacitors, switches and inputs in every phase. Add the reset switch or bias the figure shows; never add a resistor just to silence it                                                                                                                                                                                                                                        |
| `ERC_SHORTED_TRANSISTOR`              | A MOSFET has `D == S` while `B` sits on another Net (or a BJT has `C == E`). Check for an accidental wire bridge across drain/source or collector/emitter; valid MOSCAPs (`D == S == B`) and 4-pin dummies stay quiet                                                                                                                                                                           |
| `ERC_STACKED_INSTANCE`                | Two parts share the same `(x, y)` origin and overlap pins. Separate them or delete the duplicate                                                                                                                                                                                                                                                                                                |
| `ERC_UNRESOLVED_PARAMETER`            | A device parameter uses `{PARAM}` with no matching Cell formal parameter or `.param` definition. Define the parameter or replace it with a concrete value                                                                                                                                                                                                                                       |
| `ERC_DRAFTING_WIRE_IMITATION`         | A drafting line bridges electrical endpoints without connecting them in the netlist. Replace it with a real wire if connectivity is intended                                                                                                                                                                                                                                                    |
| `ERC_DRAFTING_PORT_LABEL`             | Free drafting text carries a signal name near an unnamed node. Replace it with a Net Label or formal Port                                                                                                                                                                                                                                                                                       |
| `ERC_IO_LABEL_WITHOUT_PORT`           | A connected Net carries an output, input or clock Net Label (`Vout`, `Vin`, `Clk`, `Phi1`/`Φ1`, etc.) with no formal Port, so a parent or testbench cannot drive or read it. Place a formal Port if it is an external signal, or rename it if it is internal                                                                                                                                    |
| `ERC_FLOATING_CUSTOM_SUPPLY`          | A custom supply rail (`PVDD`, `PVSS`, `AVDD`, `SAP`, `SAN`, etc.) feeds multiple MOS sources/bulks without a formal Port, supply marker or voltage source. Add a formal Port or supply source                                                                                                                                                                                                   |
| `ERC_BIAS_CURRENT_OVERDRIVE`          | An explicit `>= 1 mA` DC current source drives narrow IC MOSFETs (`>= 400 uA/um` total `w * m * nf`), which typically collapses the bias node to a rail (often an unedited legacy `1m` default). Lower `dc` (e.g. `10u`–`100u`) or widen the MOSFETs                                                                                                                                            |
| Terminal departure                    | A wire leaves a pin backward, or a port/supply/ground from the side with no other wire there; turn the symbol or approach along the pin. A bend at a lead's end, or a trunk past a tapped pin, is not reported                                                                                                                                                                                  |
| Short segment / outside page          | Review readability and intended bounds                                                                                                                                                                                                                                                                                                                                                          |
| Flightline                            | Route or label the relation, or disclose a deliberately incomplete view                                                                                                                                                                                                                                                                                                                         |

Repair the smallest responsible area. Keep clear crossings; a Junction added
to silence a warning changes topology. Zero findings does not prove
readability: review visual changes in a formal render and report issues that
affect the result.

## Response contract

Every operation answers so the next call needs no guessing, blind retry or
source reading; new actions keep these rules:

- **A refusal** names the cause, the object in the way and a concrete next
  step (the field or action to change, e.g. ambiguous names' candidate
  IDs).
- **A success** returns what the next call needs: created IDs, resolved
  references, label annotation IDs and pin landings.
- **A success that changed nothing** answers `applied:false` with an
  information finding, `NOTHING_CHANGED` unless the command gives its own
  reason (`LABELS_LEFT_IN_PLACE`); never a bare `ok`.
