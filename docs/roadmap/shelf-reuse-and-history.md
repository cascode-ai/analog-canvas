## 已实现：跨页可编辑复制

画布中选择一个或几个对象及所需导线后按 C 或 Ctrl/Cmd+C，切换到另一个工程按 V 或 Ctrl/Cmd+V，然后点击放置；Esc 取消。目标已有电路时追加，不覆盖原内容。Ctrl/Cmd+A 可选中整个画布。编辑器内的项目标签栏可新建、从文件或 Shelf 打开多个工程，保留各自视图、选区、撤销栈、保存绑定和恢复记录。未应用的代码编辑需先完成或取消，关闭未保存标签需确认。标签集合不跨刷新持久化，工作内容继续由 Cloud Save 和浏览器恢复保管。复用现有复制放置、连线推导和 Project 撤销机制，使用带版本号、经 Project Schema 校验的系统剪贴板载荷，不依赖两个页面共享缓存。

保留器件参数、位置/旋转/镜像、明确选择的导线、节点属性、标签、NoConnect 声明、自定义器件定义、引用的子模块、参数默认值及 SPICE/SCS 器件绑定。选区外的器件不会被复制；选中导线在边界引脚处转为自由端点。完整 Cell 复制还携带绑定在该 Cell/子模块范围内的仿真源文件夹及其原始文件、依赖声明；局部选区不携带整份测试平台。远程 PDK 文件仍是依赖声明，不冒充内嵌文件。

粘贴分配新的对象 ID；元件名和局部信号名冲突时自动改名。同 ID 但不同内容的自定义元件定义分开保留，明确的全局电源仍按名称连接。名字冲突涉及行为表达式、同名外部模块接口不兼容、参数默认值冲突、画布样式/格点不兼容时会明确拒绝，目标工程不发生半次修改。仿真源文本原样保留，合并到既有电路后如改了名字或接口，测试平台内的探针/分析文本需要按新电路调整。

验收包含真实 SKY130 电路网表及导线几何等价、局部选区、嵌套子模块、自定义定义冲突、局部节点隔离、撤销重做、保存重开，以及浏览器两个标签页和独立窗口中的原生 Ctrl/Cmd+C/V。代码编辑器保留文本复制粘贴；损坏或未知版本的载荷被拒绝。

## 第二优先：私人底稿版本历史

在 Cloud Project 的稳定 id 下建立不可变保存快照。首次部署从当前保存内容建立基线，不能声称恢复了从未存储过的历史。快照与当前版本的推进必须在同一事务里完成；备份包含全部保留的快照。

侧边栏 timeline 显示版本、保存时间、备注和预览。恢复旧版应新增当前版本，保留恢复前的版本；“从此版本创建副本”生成新的独立 Shelf 工程，默认不继承发布关联。恢复私人底稿不能自动更新 Gallery。

先做器件级 Diff：增删元件、W/L/m/nf、阻容值、器件映射、节点/端口连接变化；单独区分改名、移动、颜色等非电气变化。优先按稳定实例 id 对应，同构重画无法确定对应关系时标注不确定，不能强行归因。网表文本 Diff 为辅助视图。

实施前需确定保留配额及删除策略。历史丢弃必须可见，不能静默淘汰用户的命名里程碑。验收涵盖旧数据升级、并发保存、事务失败、备份恢复、恢复后撤销边界和两个账号隔离。

## 已实现：相似结构对应与画布高亮

发布窗口点击 Check Duplicate，以当前 Cell 的快照在 Worker 中查重。结果按综合相似度排序，保留所有完整拓扑匹配和最高的五个部分结构匹配；分别显示结构、参数／模型分数与元件覆盖数。Compare on canvas 打开两张只读快照，使用相同颜色标出对应元件；点击元件或列表中的一对，可查看双方位置和参数。层级实例使用完整路径，点击后进入各自实际的子 Cell，不会改动正在编辑的画布。候选 Gallery 项之后更新，也不会替换已捕获的比较图。

结构分数来自经过验证的元件／网络映射覆盖率及连接邻域相似度。元件类型、极性和引脚角色必须兼容，同一网络不能被拆开，两个不同网络不能被合并。数值参数先统一工程单位，再按大小接近程度计分；符号表达式只接受字面相等，不做代数化简。参数／模型分数中，参数占 80%、模型及调用类型占 20%；综合分数为 `结构分数 × (0.85 + 0.15 × 参数／模型分数)`。只有完整网表等价确认的结果显示 100%，管理端删除重复项仍使用原有严格网表等价检查。

对应关系有工作预算；大图或高度对称的电路达到上限会明确提示。返回的对应关系有效，但不保证是最大公共子图或所有对称映射中的最优参数配对。未摆放的器件仍可比较参数，但没有画布高亮。无法编译的电路单独计数，不能算成不存在重复；不承诺仿真结果等效。

验收包含改名／重排／无方向阻容翻转、单位等价、W/L/m/模型变化、NMOS/PMOS、二极管连接与独立栅极、串并联、部分结构、重复调用同一子模块、工作预算，以及内置 SKY130 OTA 的层级定位和尺寸变化。浏览器覆盖后台抗打断、快照隔离、对应框点击、参数查看、关闭窗口和实时画布不被修改。

如果还要求刷新、关闭浏览器后继续查重，需要另加服务端任务 id、状态存储、配额、取消与恢复接口；当前页面会话任务不能满足该条件。
