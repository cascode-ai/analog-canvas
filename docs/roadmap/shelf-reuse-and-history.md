# 工程管理、跨页复用与版本追踪

这是本次需求整理，区分已经实现的本地功能和后续工程。上线状态由提交与发布记录确认，本文不代表已部署。

| 需求 | 本次结果 | 边界 |

| Shelf 卡片管理 | 右键、长按、更多菜单；Duplicate、Rename、Export、Favorite | 副本独立，不继承 Gallery 发布关联；星标随账号保存；现有 20 个底稿上限仍有效 |

## 第一优先：跨页可编辑复制

复用 `captureProjectCopy` / `prepareProjectCopy` 的依赖收集与放置流程，增加明确版本的系统剪贴板载荷。不能直接把会话内对象或图片当成稳定协议。

必须携带选区的器件参数、几何、导线、连接点、节点属性、标签、自定义器件定义、引用的子模块、参数默认值与作用域、SPICE/SCS 源文件及所需 include 依赖。局部选区之外的连线不能被凭空带入；边界端口需要明确表达。浏览器无法读取的远程 PDK 文件不能冒充已经打包。

粘贴时为目标工程分配无冲突的实例/节点标识，并按现有连接推导规则重建网络。保留电气语义，不能因同名节点或同名子模块而误接、覆盖目标内容。一次粘贴是一次可撤销操作；校验失败不改变画布。文本框有焦点时保留原有文本复制粘贴。

验收：两个独立标签页和两个独立窗口；包含 MOS W/L/m/nf、同名节点、自定义符号、层级子电路和源文件的样例；选择局部/全选；撤销重做；保存再打开；复制前后提取的网表结构与参数等价。拒绝无法识别或被截断的载荷，给出可操作的提示。

现阶段完整迁移工程可使用 Project 文件导出/导入；这不是“局部跨页粘贴已完成”。

## 第二优先：私人底稿版本历史

在 Cloud Project 的稳定 id 下建立不可变保存快照。首次部署从当前保存内容建立基线，不能声称恢复了从未存储过的历史。快照与当前版本的推进必须在同一事务里完成；备份包含全部保留的快照。

侧边栏 timeline 显示版本、保存时间、备注和预览。恢复旧版应新增当前版本，保留恢复前的版本；“从此版本创建副本”生成新的独立 Shelf 工程，默认不继承发布关联。恢复私人底稿不能自动更新 Gallery。

先做器件级 Diff：增删元件、W/L/m/nf、阻容值、器件映射、节点/端口连接变化；单独区分改名、移动、颜色等非电气变化。优先按稳定实例 id 对应，同构重画无法确定对应关系时标注不确定，不能强行归因。网表文本 Diff 为辅助视图。

实施前需确定保留配额及删除策略。历史丢弃必须可见，不能静默淘汰用户的命名里程碑。验收涵盖旧数据升级、并发保存、事务失败、备份恢复、恢复后撤销边界和两个账号隔离。

## 第三优先：相似结构对应与画布高亮

现有结构分数只适合排序，不能把同分数视为同电路。后续在图匹配结果中返回源实例与候选实例的明确对应关系，再驱动画布高亮。层级实例用完整路径，避免多个相同子模块高亮到错误对象。

先分别显示结构相似度与参数差异，确认真实样例上的排序后再决定综合权重。器件类型、引脚角色和拓扑必须优先于参数；模型/工艺变化不能掩盖拓扑变化。电气仿真等效不是这个查重功能的承诺。

验收集至少包含：改名/重排/镜像但同电路、单位等价、仅 W/L 或倍数改变、NMOS/PMOS 互换、端口极性交换、一处断线/短接、串联与并联、子电路展开与层级表达、只共享一部分结构。比较超限或无法编译时标为无法确认，不能算作不存在重复。

如果还要求刷新、关闭浏览器后继续查重，需要另加服务端任务 id、状态存储、配额、取消与恢复接口；当前页面会话任务不能满足该条件。
