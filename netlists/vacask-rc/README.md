# Native VACASK RC fixture

[rc.sim](rc.sim) is an analytical 1 kohm / 1 uF low-pass with complex AC and
finite-rise transient input. [rc_ac.raw](rc_ac.raw) is unedited VACASK output,
not hand-authored expected values. The transient output is regenerated by the
[shared analytical qualification command and criteria](../vacask-divider/README.md).

This is not a foundry-device or hosted-runtime qualification.
