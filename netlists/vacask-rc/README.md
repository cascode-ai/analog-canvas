# Native VACASK RC fixture

[rc.sim](rc.sim) is an analytical 1 kohm / 1 uF low-pass with complex AC and
finite-rise transient input. [rc_ac.raw](rc_ac.raw) is unedited VACASK output,
not hand-authored expected values. The transient output is regenerated by the
[shared analytical qualification command and criteria](../vacask-divider/README.md).

This is not a foundry-device or hosted-runtime qualification.

[result-transient.sim](result-transient.sim) is a short 1 kohm / 1 nF pulse
response used by the numeric result-adapter contract. [result_tran.raw](result_tran.raw)
contains all 63 native solver points, captured without editing from the pinned
Windows VACASK 0.3.4 binary used by the qualification command. Run this source
in a fresh working directory with the same controlled startup and module path
to regenerate it. It is separate from the longer RC electrical-accuracy fixture.
